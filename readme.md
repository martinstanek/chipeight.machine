## How to run

*.. you should not, but*

```shell
% ./chipeight Tetris1991.ch8 http://127.0.0.1:8090
```
The first argument is the path to your ROM of choice the second one is the URL pointing to the remote HMI.\
The remote HMI is optional and if not provided, the VM will run with limited terminal display\
emulation and without any keyboard input.
